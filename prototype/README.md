# HabitForge 重想原型 · 台账

重新想过信息架构之后的前端方向原型。**只看方向，不是可运行代码** —— 没有后端、没有交互逻辑、数据是写死的样例。

## 怎么看

双击 `index.html`。每屏的**手机（390）和桌面（1280）并排**放在设备框里，顶栏可以切「并排 / 只看手机 / 只看桌面」。

每屏也是独立的响应式 HTML，可以直接单独打开，或者拖浏览器窗口宽度看断点：

```
screens/today.html     今日
screens/library.html   库
screens/review.html    回顾
screens/me.html        我
```

断点 `900px`。宽度决定形态，不做 UA 嗅探。

## 设计方向

现在的界面是 Vant 的卡片堆：白卡 + 14px 圆角 + 柔和阴影 + 橙色。重想后的材料换成了**台账 / 日记账** —— 习惯打卡的本质就是一本「做了 / 没做」的账。

- **结构**来自发丝规线和对齐，不来自卡片和阴影。层级靠字号和留白。
- **完成**是在左页边盖一枚朱砂「已」印。这是全站唯一一处"响"的东西，别处一律安静 —— 印章这个装置**只在「今日」出现**，`库 / 回顾 / 我` 都不重复它。
- **数字**一律表格数字并对齐成列，像账本的金额栏。
- **标题**用宋体。中文 App 几乎清一色黑体标题，宋体把印刷台账的文档感带进界面。
- 纸白是**冷调**的（灰绿倾向），刻意避开「米色背景 + 衬线标题 + 陶土色强调」这套通用味。

## IA：从 5 个 tab 到 4 个

| 新归属 | 吃什么 | 说明 |
| --- | --- | --- |
| 今日 | `/home`、`/plan`、`/study/review`、`/study/wrongs/practice`、`/record/create` | 从"模块摘要面板"变成一条今天要做什么的流，分三段：已排期 / 待完成 / 收尾 |
| 库 | `/habits/*`、`/study/*` | 习惯与学习并列的两棵树。**吃掉 `/study` 这个 hub 页** |
| 回顾 | `/track` + `/record` | 原来的两个 tab 合成一屏：上半是账目，下半是记录时间线 |
| 我 | `/profile` | 保持安静 |

三处结构性的改动：

1. **学习终于有了家。** 它原来有 13 个路由，却只在首页挂一张卡。
2. **`/study` 这个 hub 页被砍掉**，它承载的三样东西各自搬去了更该在的地方（见下节）：总览 → 「库 · 学习」顶部一条状态行；考试倒计时 → 今日页头；今天做了哪些题 → 今日的「今天做过」。
3. **记录 / 追踪 从 tab 位撤下来**（都是低频页），腾出的位子给库。

详情/编辑页共 12 个全部保留 —— 这次重想的是**骨架**，不是重写所有屏。

## 今日那条流的排序规则

先按段分，段内按时间：

- **已排期** —— AI 安排的时间块，有钟点，按开始时间排。唯一"有时间感"的部分。
- **待完成** —— 习惯打卡 + 今天到期的闪卡/错题混排。无钟点，**就地完成**，不跳页。
- **收尾** —— 写记录，软的，沉在底部。
- **今天做过** —— 盖了印、字迹淡下去。**不藏起来**：刷题量在这里看得见，印章也连成一条链。

习惯在段内按用户自定义顺序 —— 不拿连续天数当排序键，否则天天把同一批排前面，其他习惯永远在下面。

## 考试倒计时与刷题

- **考试倒计时**常驻**今日页头**（`考研初试 12月20日 还有 84 天`）。它是驱动今天的紧迫感，所以放在重心上；同时**库 · 学习**的每个科目行带自己的考试日期。
  用**墨色不用朱砂**：朱砂只给「已办」，倒计时跟完成是反义，抢同一个颜色会把印章的意义冲淡。要表达"来不及了"，规则是 7 天以内才转朱砂。
- **今天做了哪些题**写进今日的「今天做过」一段，带科目和数量（`专业课刷题 · 第 4 章 · 15 道`）。
- **刷题入口**：今日的待完成里有「复习到期的闪卡」和「错题重做」；**库 · 学习**下有题库、错题本。
